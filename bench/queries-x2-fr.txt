# The French counterpart of queries-x2.txt (ticket 0091, the multilingual arm).
#
# Why it exists. The argument for deriving the common-word list from the library rather
# than shipping one turns on a token space that holds every language at once. That claim
# cannot be tested against a query set in which every query is English, and the library
# this is measured on is 11,8 % French by passage sample — so the French queries are real
# users' queries, not a hypothetical.
#
# How it is built. Twenty questions of the same shape and the same subject matter as the
# English set — climate and energy economics, the history of economic thought, Vietnam —
# because the two sets have to differ in language and in nothing else, or the comparison
# measures the topic instead. Each carries the French function words a French speaker
# cannot avoid: le, la, les, des, une, dans, pour, sur, est, sont, qui, que.
#
# Line 20 is the French analogue of `to be or not to be`: a query made of nothing but
# function words. It is the degeneracy case in a language no shipped stoplist covers.
#
# What it is expected to show, stated before running so the result can contradict it: at a
# 30 % cutoff on THIS library no French function word is prunable — `des` is the most
# common at 5,04 % — so the droplist should prune nothing here and French queries should
# cost the same in every arm. That is the rule behaving correctly, and it is also the
# reason the language claim needs the French-majority sub-index to be demonstrated.
