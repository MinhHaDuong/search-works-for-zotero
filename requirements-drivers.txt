# What the measurement drivers need, beyond the gate's set (ticket 0498).
#
# These are the heavy two: a model runtime and the library that loads a
# sentence-transformer on top of it. Nothing under `make check` imports either,
# which is the whole reason for the split — the gate is runnable on a machine
# that will never embed anything.
#
#     python3 -m pip install -r requirements-check.txt -r requirements-drivers.txt
#
# Unpinned, deliberately: every number that decides what a measurement means is
# pinned in `bench/models.json` instead, and a driver that cared about a library
# version would have to record it in the result file rather than here.

sentence-transformers
torch

# Mojibake detection for the ticket-0480 full-text quality census. Optional at
# runtime — `bench/fulltext_quality_census.py` reports the column as null rather
# than as clean when it is absent, and the suite skips the assertions that need
# it — but declared here because the committed artifact was measured with it and
# a re-run without it is not the same measurement.
ftfy

# SDT tensor replay (ticket 0674). The default distribution runs the CPU arm.
# In a separate CUDA replay environment, install onnxruntime-gpu INSTEAD of
# onnxruntime: both distributions provide the same Python import. The measured
# version and actual providers are recorded with the result, not assumed here.
onnxruntime

# AT-SPI2, for reading the sitter panel as an assistive technology sees it
# (ticket 0769). `verification/probes/atspi_*.py` walk Zotero's accessible tree
# from OUTSIDE the process -- the reading the plugin's own aria-label cannot
# give, because that asserts what the markup says rather than what the
# accessibility layer computed from it.
#
# Import name `gi`. Normally already present as the distribution's python3-gi
# and NOT installed through pip; the typelib it loads (Atspi-2.0) is a system
# file that a wheel cannot supply. Declared here because the probes import it
# and this file is where the gate looks, not because pip is how to get it.
PyGObject
